**Two corrections to the report — read before trusting it:**

1. **#12's stated trigger is wrong.** `readUnsignedInt` *does* guard `value < 0`
   ("unsigned int exceeds positive int range"), so the report's
   "接近 Integer.MAX_VALUE" example `0xFFFFFFF0` is rejected safely. But the
   guard only blocks negatives — `0x7FFFFFF0` passes and still OOMs
   (`OutOfMemoryError: Java heap space`). Bug real, example value wrong.
2. **Parameter-order trap in `submitScore`.** My first #10 repro passed `score`
   where `uid` belongs → `rank=1`, looked like a false positive. Correct order:
   `submitScore(rankingId, seasonId, uid, score, tieBreakValue, mode, key)`.
   After fixing, #10 confirms (`queryPlayerRank(p149)=rank150`, unreachable via
   `queryTop`). Worth knowing: shallow argument mismatch can fake a "not a bug".

**Not re-verified:** #13 (codegen traversal), #14 (metric registry unbounded),
S1–S4. Checkstyle/PMD/SpotBugs still never run.

**Maven invocation note:** the classworlds launcher needs **three** props, not
just the classpath — omitting any one fails with a misleading error:
```
-Dmaven.home="D:\env\apache-maven-3.9.8"
-Dclassworlds.conf="D:\env\apache-maven-3.9.8\bin\m2.conf"
-Dmaven.multiModuleProjectDirectory=L:\zero-server
```
`-Dmaven.home` missing → `ConfigurationException: No such property: maven.home`.
No `-Dclassworlds.conf` → `classworlds configuration not specified`.
`./mvnw` and `mvn` under Git Bash both still break on POSIX `JAVA_HOME`
(both gave `ClassNotFoundException: ...classworlds.launcher.Launcher` even with
`JAVA_HOME="D:\env\jdk21"`).
