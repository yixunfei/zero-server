# 审计 B5 迁移说明

日期：2026-10-08。适用当前 `0.1.2-SNAPSHOT` 开发预览；不改版本、不发布。用户已批准 B5 方案 v1。编号事实与验证证据存放在本机 `tasks/archive/20261008-audit-remediation/b5/`，该目录按仓库规则不进入 Git。

## API 与行为变化

| 模块 | 新行为 | 接入要求 |
| --- | --- | --- |
| core lifecycle | `doStart/doStop` 不再全程持有实例监视器；STARTING 的 stop、STOPPING 的 start 快速拒绝；同向请求幂等 | 子类不能依赖钩子跨越状态锁；`beforeStartRequest` 仍在锁内并先于幂等短路，single-use 校验保留 |
| runtime | 成功 STOPPED 后 close 直接发布 CLOSED；FAILED 清理继续按账本重试 | runtime 控制编排仍串行，不能把组件快速拒绝当成整个 runtime 的硬关闭时限 |
| bootstrap | `ZeroRuntimeExecutors` 可注入正 `closeTimeout`，默认 3 秒；维护停止由固定 30 秒改为该预算 | 组合根按驱动延迟选择预算；timer 先停止/等待，超时请求中断，随后关闭自有 worker；借用执行器不关闭 |
| event | `EventInterceptor.afterPublish(event, failure)` 默认方法；已进入 before 的拦截器逆序清理，包括拒绝/抛错者；publish 在清理后完成 | 钩子短时、非阻塞，不等待本次 publish，不依赖与 before 同线程；完成钩子不提供线程本地 MDC 对称保证 |
| world | 默认总迁移收据容量 4096，可通过新增构造参数设正值；`migrationCount()` 查询 | 新 ID 满时在实体冻结前以 `MIGRATION_CAPACITY_EXCEEDED` 拒绝；旧 ID 指纹、重放与既有推进继续；无自动终态淘汰，容量耗尽需轮换服务生命周期或另选持久实现 |
| world enum | 删除无生产引用的 `MigrationState.REQUESTED/HANDOFF_SENT` | 外部 switch 与依赖旧枚举的源码必须更新并重编译；没有存储兼容层 |
| scene | 未进入实体的 move 以 `SceneErrorCode.NOT_ENTERED` 异步失败，不创建空场景目录 | 调用方以领域错误处理；同 UID 在不同 scene 的独立实体仍允许，独占玩家切场由业务编排 |
| room | 创建通知及 scheduler 转交在锁外；CREATED 结束前的命令 FIFO 暂存，最多 4096 条 | 独立暂存上限覆盖创建/内联回调阻塞窗口，超额以 SYSTEM_ERROR 失败，之后仍由 scheduler 控制预算；通知失败不撤销已发布房间 |
| room terminal | CLOSED 后 leave/disconnect/reconnect/ready 均拒绝 | close 幂等、destroy 删除、完全相同 settlement 只读重放保留；回调不得等待自身 lane 后续命令 |
| npc | 删除同步 `spawn/despawn/tick`，使用返回 CompletionStage 的 `spawnAsync/despawnAsync/tickAsync`；ZoneActor 接受 ActorScheduler 接口 | 用组合完成链连接后续业务，禁止在 Actor/IO 线程 join；全部修改与 `ZoneActor.laneKey()` 的其他消息排序，不新建执行器 |
| logic | 同连接对象 open 幂等，同 ID 异对象以 CONNECTION_CONFLICT 拒绝；close 仅匹配当前对象 | 所有断线路径显式 close；默认 65536 会话，可设置正容量；close 释放容量，旧引用读可诊断、写及 markRequest 以 SESSION_CLOSED 拒绝 |
| logic attributes | 同 name 仅允许一种活跃类型，不匹配访问以 ATTRIBUTE_TYPE_CONFLICT 拒绝；删除释放类型；update null 删除 | updater 必须短时、非阻塞，不递归修改容器，也不得跨会话/manager 调用形成锁环；请求 count/time/interval 一起提交，独立多次读不承诺事务快照 |

NPC 状态短锁不包围 adapter/event/audit/metrics。回调提交的修改排在当前命令之后；tick 只取一次候选快照。已提交状态遇通知故障不回滚，所有通知尝试后聚合；普通 adapter Exception 隔离为 BEHAVIOR_FAILED，adapter Error 终止本次 tick 并保留 tick 指标、异步失败。任何预算为零不调用 adapter。同步 adapter 超过预算不能被安全强杀，预算只控制后续准入。

`examples/npc-tick` 实际使用独立 `LocalNpcTickApi`，生成模板使用私有 NpcStore；它们没有正式 LocalNpcZone 消费路径，不能据 smoke marker 声称验证了正式 zone lane。

## 保留契约与能力缺口

- Event 不自动重试，不提供通用持久幂等；完成钩子只解决事件级清理配对。
- World 创建接受非零初始 routeEpoch，拓扑仍静态；没有在线换代、重建或跨进程 fencing。
- Scene 不提供全局 UID 排他；Logic 不自动按空闲时间踢线。
- GameRuntime 为 single-use；Lifecycle.state 是 runtimeState 的有损投影。缺配置 diagnosis 的 Optional.empty 表示尚不能规划，不伪造完整计划。
- 配置空白高优先级不回退；origin 保留来源，reloadability 来自键声明。RuntimeDeadline 注入时钟必须单调；健康探针必须及时返回 stage，不能依赖启动控制线程推进。
- 生产诊断生命周期保留启动首失败，显式 fail 可替换，mark 非 FAILED 清理旧错误。containsFragment 仅供测试/诊断，不是安全判定 API。
- Actor close 失败排队项，已进入业务的在途消息仍由真实完成释放许可。Scheduler 同步异常由执行入口捕获，取消/快照/observer/容量分属现有接口。
- 日志 provenance 仅在当前管线可信；CSV 是本地配置热重载，不代表类热更或远程授权。观察者失败不回滚已接受快照，watcher 主故障保留观察故障并在停止时报告。指标底线不保证任意业务标签的低基数。
- 关闭累计预算只限制框架等待；超时 timer/driver 若忽略中断，仍可能运行或晚到提交。不要将取消/超时等同于物理停止或生产 SLA。
- 生命周期基类去锁不删除子类显式资源锁（例如 KcpServer 的停止串行保护）。Nacos 以显式短锁保护 SDK 操作准入计数/等待，SDK 和回调在锁外；停止期间句柄取消由统一清理负责。stop 等待已准入 SDK 操作实际返回，保留提交一致性，没有增加驱动硬关闭时限。

## 验证口径

Java 21 顺序执行受影响模块测试、全仓 `-Pquality,benchmarks verify`、保护模块 API 符号/独立消费者检查和相关独立示例。精确最终数量、运行时间、退出码和实际执行 XML 见本机 B5 VERIFY 与 evidence；失败尝试保留并标明夹具错误或真实红证据。benchmarks 仅编译，不声称执行 JMH；外部数据库/MQ、长稳、生产容量和跨机行为不在本批验证范围。

全仓质量构建成功：63 reactor、47 个有测试模块、324 suite、1248 测试（1247 通过、0 失败/错误、1 Redis 外部环境跳过）。benchmarks 的现有单测实际执行，JMH 未运行。随后仅补一项 Nacos 停止窗口测试，相关依赖闭包 quality 为 11 reactor、162 测试全部通过，其中 Nacos 并发测试 7 项；与全仓计数有重叠，不相加。

四个独立示例 test/exec 成功：npc-tick 3 项、world-shard/room-game/rpg-tcp-generated 各 1 项，TCP 实际断线后 sessionsClosed=true。5 模块小消费者编译通过。API 符号基线检查退出码 1，仅发现旧无参 `readPresenceBits()` 缺失；这是[2026-10-07 N 系列迁移](20261007-audit-n-series.zh-CN.md)已声明的源码/二进制破坏性变更，当前方法需可信 schema 参数，本批未改其源码/基线。不声称所有 API 门禁通过，也不据示例通过承诺外部兼容。
