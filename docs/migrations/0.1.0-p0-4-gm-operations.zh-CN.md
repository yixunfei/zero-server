# 0.1.0 P0-4 GM operations migration note

本切片新增 GM 生产运营边界契约：

- 有界审计查询、cursor 分页、retention/archive 端口；
- 显式业务幂等 store 和 REST/RPC operation request idempotency key；
- break-glass grant 的 scope、operation fingerprint、TTL 和一次性消费；
- parse/transport failure 的安全字段载体；
- transport-neutral GM RPC request/response boundary。

兼容旧 `GmOperationRequest` 构造器；应用应逐步改为显式传入 idempotency key，并使用持久化 store。`InMemoryGmIdempotencyStore` 与 `InMemoryGmBreakGlassProvider` 仅适合 local/test，不能替代数据库、审批系统或真实身份平台。

本切片不实现真实 HTTP server、Kafka GM adapter、持久 RBAC/IP/审批、审计数据库 durability、完整失败审计接入或生产 break-glass 运营流程。整体 `productionReady=false`、`goalAchieved=false` 保持。
