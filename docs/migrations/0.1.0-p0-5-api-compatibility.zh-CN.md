# 0.1.0 P0-5 API/SPI 兼容迁移说明

## 新增

- 跟踪的核心 API surface baseline：`zero-core`、`zero-runtime`、`zero-protocol`、`zero-rpc-common`、`zero-data`。
- `scripts/VerifyPublicApiCompatibility.java` 删除/可见性/签名变化检查。
- `scripts/VerifyApiCompatibilityConsumer.java` Java 21 独立 consumer compile。
- CI `compatibility-gate` job 和 API compatibility artifact。

## 兼容边界

当前 `0.1.0-SNAPSHOT` baseline 是 bootstrap 快照，不是历史 release ABI。门禁默认允许新增 public API，但阻断已记录 API 的删除和签名变化。新增公共 SPI 仍需经过评审、迁移说明和相关模块测试。

配置 key、协议 ID、provider ID、所有 Adapter API、泛型/注解/JVM linkage 级别的完整二进制比较，以及正式 japicmp/Revapi baseline，仍属于后续增强范围。
