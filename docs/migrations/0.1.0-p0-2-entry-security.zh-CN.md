# 0.1.0 P0-2 入口安全迁移说明

## 变更

`zero-security` 新增显式安全 SPI：

- `AuthenticationProvider`
- `ReplayProtection`
- `TlsMaterialProvider`
- `SecurityContext`
- `SecurityChain`
- `SecurityContextBridge`

Production network builder 新增 `securityChain(SecurityChain)` 组合入口。生产 TCP 安全策略会在认证成功后绑定不可变 `SecurityContext`，并对后续请求执行权限、过期和重放门控。

## 兼容与迁移

- local TCP 默认行为保持不变。
- 使用 production network lifecycle 的应用应显式提供 `SecurityChain.production(...)`，并提供上层认证、重放和 TLS 材料 provider。
- 未提供安全 provider 的兼容组合使用 fail-closed 语义；不得将其作为公网配置。
- `TlsMaterialProvider` 当前只定义受控快照和轮换边界，不负责加载 keystore 或私钥；证书 adapter 需要由应用显式实现。
- HTTP/RPC context bridge 只提供显式作用域传播契约，尚不代表完整 HTTP 网关、Kafka 认证或跨进程安全 metadata wire format。

## 非目标

本切片不内置账号系统、JWT/SSO、WAF/DDoS、分布式限流、外部证书供应商、完整公网容量或长稳证明。生产就绪状态仍保持 `productionReady=false`。
