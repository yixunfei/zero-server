# 0.1.0 P0-4 GM 生产运营边界迁移说明

## 新增

- 有界 `GmAuditQuery` / `GmAuditPage` / `GmAuditQueryStore` 查询契约。
- `GmAuditRetentionPolicy`、`GmAuditArchiveSink`、`GmAuditRetention` 留存/归档边界。
- `GmIdempotencyStore` 与本地参考实现，支持 claim、重复完成结果、fingerprint conflict、TTL 和未知状态 fail-closed。
- `GmBreakGlassGrant`、`GmBreakGlassProvider`、`GmBreakGlassAuthorization` 紧急授权边界。
- `GmSecurityFailure` 解析无关的安全失败审计载体。
- `GmRpcTransportAdapter` 传输中立 RPC 边界。

## 兼容和安全边界

现有 `GmOperationRequest` 保留旧构造器；新增 `idempotencyKey` 可由 REST/RPC transport 显式传入。应用必须提供持久幂等 store、身份/RBAC、审批和真实 RPC/HTTP adapter。内存实现仅用于 local/test，不能作为生产持久性证明。

本切片不包含真实 HTTP server、Kafka 认证、数据库存储、账号系统、持久 RBAC、WAF/DDoS 或完整 break-glass 运营流程；整体 `productionReady=false` 保持。
